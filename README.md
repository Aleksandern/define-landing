# DeFine

DeFi risk observability and early warning system for EVM blockchains.

## Overview

DeFine monitors wallet exposure across EVM protocols and converts on-chain state into actionable risk signals, security warnings, and explainable alerts.<br />
The goal is to make DeFi risk understandable and actionable through deterministic evaluation and early signals.

## Status

The core system is currently developed in a private repository.<br />
Reusable components are being released as open-source through the **DeFine Kit** project:
https://github.com/Aleksandern/define-kit
